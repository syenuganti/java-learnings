# Facade Pattern

The Facade pattern provides a simplified interface to a complex subsystem. It acts as a convenient wrapper that reduces the complexity and dependencies of a system.

## Real-World Analogy
Think of ordering food from a restaurant:
- You don't interact with the kitchen staff directly
- You don't need to know about food preparation details
- You just tell the waiter what you want
- The waiter coordinates with kitchen, billing, etc.

## Problem It Solves
- Simplifies complex subsystem interfaces
- Reduces dependencies on external code
- Makes subsystems easier to use
- Provides a unified interface to a set of interfaces

## When to Use
- When you need a simplified interface to a complex subsystem
- When you want to layer your subsystems
- When you want to reduce tight coupling between clients and subsystems
