# Decorator Pattern

The Decorator pattern allows adding new behaviors to objects dynamically by placing them inside wrapper objects that contain these behaviors.

## Real-World Analogy
Think of ordering coffee:
- Start with a basic coffee
- Add extras (milk, sugar, whipped cream, etc.)
- Each addition "decorates" the coffee with new functionality
- The final price is the sum of all additions

## Problem It Solves
- Adds responsibilities to objects dynamically
- Provides flexible alternative to subclassing
- Supports Single Responsibility Principle

## When to Use
- When you need to add responsibilities to objects dynamically
- When extension by subclassing is impractical
- When you want to add optional features to a core object
