# Design Patterns Learning Guide

This project contains practical implementations of the most commonly used design patterns in Java. The patterns are organized into three main categories:

## 1. Creational Patterns
- Singleton Pattern
- Factory Method Pattern
- Abstract Factory Pattern
- Builder Pattern
- Prototype Pattern

## 2. Structural Patterns
- Adapter Pattern
- Bridge Pattern
- Composite Pattern
- Decorator Pattern
- Facade Pattern
- Flyweight Pattern
- Proxy Pattern

## 3. Behavioral Patterns
- Observer Pattern
- Strategy Pattern
- Command Pattern
- State Pattern
- Template Method Pattern
- Iterator Pattern
- Mediator Pattern
- Chain of Responsibility Pattern

Each pattern implementation includes:
- Problem it solves
- Real-world example
- Implementation with detailed comments
- Usage demonstration

## How to Use This Guide
1. Start with the pattern you want to learn
2. Read the README.md file in each pattern's directory
3. Study the implementation
4. Run the example code
5. Try modifying the examples to reinforce learning
